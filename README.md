# Nexora – Team Project & Workflow Organization

A responsive SaaS landing page for a productivity platform that helps teams organize projects, manage tasks, and coordinate workflows.



🚀 Live Demo
Try Nexora Team Project Workflow Organisation here:https://satyamrajput01.github.io/Nexora-Team-Project-Workflow-Organisation/



## Features

- Interactive workspace demo with view switching and task checklists.
- Monthly and annual pricing toggle.
- Accessible FAQ accordion.
- Registration modal with client-side validation.
- Dedicated Privacy Policy and Terms of Service pages.
- Responsive design with keyboard accessibility.

## Tech Stack

- HTML5
- CSS3 and Tailwind CSS
- Vanilla TypeScript
- Vite

## Run Locally

Requires Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL displayed in your terminal.

## Deployment

Hosted using GitHub Pages.


## Note

This is a frontend-only student demonstration project. It does not include a backend, account creation, or data storage.
